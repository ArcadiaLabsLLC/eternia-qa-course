# The first lesson folder

This lesson is a **QA fixture**. It is a folder holding `index.html` and
`lesson.md` — the course repo format (v2) — and Eternia draws the folder's
`index.html` as a Template.

## What to look for

- a heading and a sub-heading
- a bulleted list with *emphasis* and `inline code`
- a numbered list:
  1. open the course
  2. open this lesson
  3. read to the end

> A quote block, so the reader can check its style.

```text
a code block
  keeps its indentation
```
