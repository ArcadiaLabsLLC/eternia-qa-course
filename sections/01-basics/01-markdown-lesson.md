# A Markdown lesson

This lesson is a **QA fixture**. It is one Markdown file, the course repo
format's first shape (v1), and Eternia draws it through its lesson converter.

## What to look for

- a heading and a sub-heading
- a bulleted list with *emphasis* and `inline code`
- a numbered list:
  1. open the course
  2. open this lesson
  3. read to the end

> A quote block, so the reader can check its style.

```text
a code block
  keeps its indentation
```
